This page works locally without an HTTP service, login, or network requests. Inventory metadata stays in this file and your browser. Keep this HTML and its CSV private.

Review workflow

  1. Check the automatic group summary below, then search or review the table. Search only filters the table; selected rows stay selected while hidden. The count shows how many selected rows are hidden.
  2. Change group labels separated by semicolons (;) and check Apply to pin a decision. Unchecked rows keep their automatic proposal. Exclude removes an applied row from all groups. Use the selection controls for explicit bulk changes; reset selected rows to their automatic proposals when needed.
  3. Download a decisions CSV only when you need overrides (it includes every row, including untouched proposals). Pass the actual downloaded file location as -ReviewPath to the grouping workflow. Identity and raw descriptions cannot be changed here.

Your browser controls the download folder or Save As prompt. This page cannot modify WUG, save a browser profile, or change existing files; closing or reloading it loses unsaved edits.
